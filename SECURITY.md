# Security Policy

## Escopo

O RaceMetrics está em desenvolvimento. A segurança é tratada como requisito de arquitetura, especialmente para autenticação, autorização, privacidade dos dados e proteção das contas.

## Como reportar uma vulnerabilidade

Não publique credenciais, tokens, dados pessoais ou detalhes de uma vulnerabilidade explorável em uma issue pública.

Para um reporte responsável, utilize os mecanismos privados de segurança disponibilizados pelo GitHub para este repositório, quando habilitados. Se esse canal não estiver disponível, abra uma issue sem incluir detalhes sensíveis e solicite um canal privado de contato.

## Boas práticas

- Nunca envie segredos, tokens ou senhas para o repositório.
- Não use dados pessoais reais em testes.
- Não tente acessar contas ou dados de terceiros.
- Vulnerabilidades confirmadas devem ser corrigidas antes de serem documentadas publicamente.

## Status

Esta política acompanha a evolução do projeto e será ampliada quando a autenticação, persistência e infraestrutura de produção estiverem consolidadas.
